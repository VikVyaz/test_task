# Тестовое задание

## О проекте
Fullstack Django приложение по ТЗ с аутентификацией и регистрацией.

## ✨ Основной функционал

* Аутентификация и регистрация
* CRUD для User.
* Слайдер реализован через slick slider (Slider Syncing)
* Использован django-filer
* Использован django-admin-sortable2 для drag&drop

## 🛠 Технологии и стек
* Python 3.12
* Django
* MySQL
* Bootstrap 5
* Базовые знания в HTML, CSS, JS
* GIT
